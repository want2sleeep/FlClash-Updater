# FlClash Updater

为 Windows 上的 FlClash 提供自动检查、下载和安装更新的工具。本仓库当前只记录需求与方案，不包含程序实现。

## 目标

让本机 FlClash 能够可靠地获取 GitHub 正式版更新，并由用户控制自动更新行为和安装时机。

## 推荐形态

- 轻量 Windows 桌面程序，提供设置窗口和系统托盘入口。
- 后台检查与安装由 Windows 计划任务触发；用户可以暂停自动更新、手动检查、立即安装和查看日志。
- 先确认本机 FlClash 的安装方式、位置、架构和权限，再确定升级执行方式。

## 更新规则

- 更新源：`chen08209/FlClash` 的 GitHub Releases。
- 默认只采用稳定正式版，不采用预发布版本。
- 提供两种可配置模式：
  1. **下载后尽快安装**：下载、校验完成后等待满足安装条件，再尽快升级。
  2. **定时安装**：下载、校验完成后，在用户设置的本地时间窗口安装。
- 默认启用“正式版发布满 24 小时后才允许自动安装”，该等待期可由用户调整或关闭。
- 定时模式下，电脑关机或休眠时不主动唤醒；错过安装时段后等下一次时段，不在开机时立即补装。
- 提供手动立即检查和立即安装操作；手动操作是否遵守 24 小时等待期，需在产品设置中明确，推荐仍遵守并提供明确覆盖操作。

## 升级流程

1. 检查正式版元数据，比较本机与最新版本。
2. 按当前架构选择官方安装包，下载到缓存目录。
3. 下载完成后校验发布页提供的 SHA-256 摘要；校验失败时不安装。
4. 满足模式、时间和等待期条件后，备份配置并尝试正常退出 FlClash。
5. 使用官方安装包升级，保留原安装目录和用户配置。
6. 启动 FlClash 并验证安装版本；记录结果并通知用户。

## 失败与恢复

- 第一版记录日志、通知失败，并限制自动重试频率。
- 保留配置备份和已下载的安装包，便于诊断和手动恢复。
- 第一版不承诺自动回滚；需要先验证旧版与新版配置兼容性和安装器行为。
- 安装及重启失败时，不删除现有配置或缓存证据。

## 安全与权限

- 仅从配置的官方 GitHub 仓库读取发布信息和下载资产。
- 校验下载文件后才执行安装程序。
- 优先使用当前用户权限；如果安装位置或安装器要求管理员权限，再设计首次授权流程。
- 安装版优先使用官方安装包，不直接覆盖程序目录。解压版是否支持更新需另行设计。

## 待确认事项

- 更新时采用轮询 GitHub Releases 还是支持其他分发源。
- 手动“立即安装”是否允许覆盖 24 小时等待期。
- 成功通知是否默认开启，以及 Windows 通知不可用时的提示方式。
- 配置备份范围、保留数量和清理周期。
- 计划任务以当前用户权限运行还是按需提升权限。
- 正式版安装包的静默参数、退出方式、服务处理和安装后启动验证。
- 是否支持 ZIP 便携版，以及回滚能力的实际边界。
